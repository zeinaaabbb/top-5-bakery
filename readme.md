# 🥐 London's Best Bakes

A simple website which shows some of my favourite pastries and baked goods across London.

From honey butter toast in Covent Garden to cinnamon rolls in Shoreditch, this project is a small guide to some of the best bakes I've tried.

## 🍞 Featured Bakeries

The current top five are:

1. Arome Bakery — Honey Butter Toast 📍 Covent Garden

2. Mahali Bakery — Pandan Almond Croissant 📍 Battersea

3. Pophams — Cardamom Bun 📍 London Fields

4. Roll Boys — Cinnamon Roll 📍 Shoreditch

5. Farha — Shakshuka Buns 📍 Leyton
